<div align="center">
  <h1>🟡 <span style="color: #FFD700;">Pokédex.</span> 🟡</h1>
</div>

<div align="left">
<p>Proyecto práctico desarrollado para la materia <strong>Programación Web 2</strong>.</p>

<p>Pokédex es una aplicación web dinámica e interactiva que representa una Pokédex completa. Permite a los usuarios consultar y buscar información detallada de distintos Pokémon, e incluye un panel de administración restringido con sistema ABM (Alta, Baja y Modificación) persistido en base de datos.</p>

 <br>
   
<h2>✨ CARACTERÍSTICAS: </h2>
<p>
🔐 Sistema de autenticación de administrador mediante sesiones (`$_SESSION`).<br>
🔍 Buscador por nombre o número único de Pokédex.<br>
📋 Listado general con tarjetas descriptivas.<br>
🏷️ Representación visual de los tipos (Fuego, Agua, Planta, etc.) mediante imágenes.<br>
📖 Vista individual de detalle en página completa.<br>
➕ Formulario de alta para registrar nuevos Pokémon y subir su imagen.<br>
✏️ Edición de datos y rutas de imagen para Pokémon existentes.<br>
❌ Eliminación física de registros en la base de datos.<br>
</p>

<br>

<h2>⚙️ FUNCIONAMIENTO DEL SISTEMA: </h2>
<p>
1. 🌐 Ingresar a la página principal y explorar la lista de Pokémon.<br>
2. 🔍 Buscar un Pokémon específico por su nombre o número.<br>
3. 📖 Seleccionar un Pokémon para acceder a su ficha detallada.<br>
4. 🔐 Iniciar sesión en la plataforma con cuenta de administrador.<br>
5. ➕ Cargar nuevos Pokémon completando el formulario de alta.<br>
6. ✏️ Modificar la información o imágenes de los Pokémon registrados.<br>
7. ❌ Dar de baja registros que ya no correspondan.<br>
8. 🚪 Cerrar sesión de administración de forma segura.
</p>
